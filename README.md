# Taskist Studio — Downloads

Este repositório contém somente os arquivos oficiais de instalação do Taskist Studio.

## Versão atual

- [Windows 64-bit — Taskist-Studio-v2.4.2.exe](https://github.com/arthurfpol/taskist-releases/releases/download/v2.4.2/Taskist-Studio-v2.4.2.exe)
- [Android — Taskist-Studio-v2.4.2.apk](https://github.com/arthurfpol/taskist-releases/releases/download/v2.4.2/Taskist-Studio-v2.4.2.apk)

No Windows, feche o Taskist pelo ícone da bandeja usando **Sair completamente** antes de abrir uma atualização. No Android, o APK usa a mesma assinatura das versões anteriores.

Os hashes SHA-256 e os manifestos estão anexados a cada release. Versões anteriores ficam na aba [Releases](https://github.com/arthurfpol/taskist-releases/releases).

O código-fonte e o desenvolvimento são mantidos separadamente.
